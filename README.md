# 🛡️ مشروع تطبيق حماية راوتر Cisco وتأمين الشبكات المنطقية
### (Cisco Router Security & Inter-VLAN Routing Lab)

يقدم هذا المشروع بيئة عمل شبكية متكاملة تعتمد على راوتر Cisco IOS، ويهدف إلى تحقيق التوازن بين الأمن السيبراني وإدارة الشبكات[cite: 1]. يركز المشروع على حماية الجهاز الإداري وتنفيذ العزل الشبكي والتوجيه بين عدة شبكات افتراضية مستقلة[cite: 1].

---

## 🛠️ الميزات والمهام الفنية المطبقة

### 1. تأمين الوصول والإدارة (Administrative Security)
* **حماية وضع الامتياز:** استخدام `enable secret` لتشفير كلمة مرور الوضع التنفيذي[cite: 1].
* **التشفير والاتصال الآمن:** حظر بروتوكول Telnet وتفعيل **SSH v2** باستخدام مفاتيح RSA[cite: 1].
* **إدارة الحسابات والمنافذ:** إنشاء حساب إداري محلي وتأمين منافذ التحكم (`Console` و `VTY`) وتفعيل تشفير كلمات المرور[cite: 1].
* **الحماية من الهجمات:** تقييد محاولات الدخول التخمينية (Brute Force) عبر خيار `login block-for`[cite: 1].

### 2. تقسيم وعزل الشبكات (Network Segmentation)
* **Router-on-a-Stick:** إعداد التقنية عبر المنفذ الأساسي لاستقبال الحركة الموسومة ببروتوكول IEEE 802.1Q[cite: 1].
* **الواجهات الفرعية (Sub-interfaces):** إنشاء واجهات مخصصة لثلاث شبكات منطقية منفصلة (`VLAN 10`, `VLAN 20`, `VLAN 30`)[cite: 1].

### 3. إدارة العناوين والخدمات (Services & IP Management)
* **خادم DHCP:** إعداد الراوتر لتوزيع العناوين تلقائياً للشبكات الثلاث، مع استثناء عناوين البوابات والأجهزة الحساسة[cite: 1].
* **تقليل مساحة الهجوم (Attack Surface):** تعطيل الخدمات الإدارية غير المشفرة مثل `HTTP Server`[cite: 1].
